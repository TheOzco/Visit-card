# کارت ویزیت دیجیتال — دکتر محمد محمودیه دهکردی

یک صفحهٔ کارت ویزیت دیجیتال (ریسپانسیو، راست‌به‌چپ) با بخش «مراقبت‌های پس از درمان»،
لینک پیام‌رسان‌ها (تلگرام، اینستاگرام، ایتا، بله، روبیکا) و دکمهٔ مسیریابی مستقیم به مطب.

## ۱) ویرایش اطلاعات

همهٔ متن‌ها و لینک‌ها در فایل `src/data.ts` هستند و فقط باید همان را ویرایش کنید:

- `doctor` : نام، تخصص، نشانی مطب، ساعات ویزیت، شماره تماس
- `links` : آیدی و لینک پیام‌رسان‌ها (جای `dr_mahmoudieh` را با آیدی واقعی عوض کنید)
- `mapHref` : لینک لوکیشن مطب (از گوگل‌مپس «اشتراک‌گذاری → کپی لینک» بگیرید)
- `care` و `redFlags` : متن‌های مراقبت‌های پس از درمان

## ۲) عکس و لوگو

- عکس پروفایل: فایل `public/images/profile.jpg` را با عکس واقعی جایگزین کنید (نسبت ۳:۴ / عمودی).
- لوگو: در انتهای صفحه «جای لوگو» گذاشته شده است. برای قرار دادن لوگو، فایل
  `public/images/logo.png` را اضافه کنید و در `src/components/Ornaments.tsx` داخل
  کامپوننت `LogoSlot` یک `<img src="images/logo.png" />` قرار دهید.

## ۳) انتشار روی گیت‌هاب با گوشی

1. در گوشی، اپ **GitHub** را نصب کنید و وارد حساب خود شوید.
2. یک مخزن (Repository) جدید بسازید؛ نام دلخواه، عمومی (Public)، بدون README.
3. همین پوشهٔ پروژه را در گوشی «دانلود / ZIP» کنید (دکمهٔ سبز **Code → Download ZIP**)،
   از حالت ZIP خارج کنید و فایل‌ها را در اپلیکیشن GitHub آپلود کنید (`Add file → Upload files`).
4. در همان مخزن: **Settings → Pages → Build and deployment → Source: Deploy from a branch**،
   شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید و **Save** بزنید.
5. پس از چند دقیقه، نشانی سایت در همان صفحه نمایش داده می‌شود:
   `https://نام-کاربری.github.io/نام-مخزن/`

> نکته: خروجی بیلد یک فایل `dist/index.html` و پوشهٔ `dist/images` است. اگر می‌خواهید
> بدون بیلد منتشر کنید، محتویات `dist` را مستقیم در شاخهٔ `main` آپلود کنید.

## ۴) اجرا روی سیستم محلی

```bash
npm install
npm run dev
```

برای ساخت نسخهٔ نهایی: `npm run build`
